# BoNa Mebel — Новый сайт с эффектом Liquid Glass и авто-синхронизацией из VK

Современный, строгий и минималистичный сайт для мастерской корпусной мебели **BoNa** (Курск и область).

---

## 🌟 Ключевые возможности проекта

1. **Дизайн в стиле Liquid Glass (Жидкое стекло):**
   - Строгая монохромная эстетика: глубокий графитовый черный, чистый белый, мягкие блики и преломления.
   - Фиксированная верхняя навигационная панель (`site-header`), плавно переходящая в матовое жидкое стекло (`backdrop-filter: blur(24px) saturate(190%)`) при прокрутке страницы вниз.
   - Отдельная выделенная кнопка перехода на страницу мастера ВКонтакте (`vk.ru/drozdova_natasha`) в самом верху шапки.
   - Плавные анимации появления, парящие карточки с гранями света и мягкими тенями.

2. **Фиксированная вкладка «Примеры работ» с категориями:**
   - Липкая панель фильтров: **«Все работы»**, **«Кухни»**, **«Шкафы-купе»**, **«Прихожие»**, **«Детские & Спальни»**, **«Ванные & Гардеробные»**.
   - Фото кухонь распределяются во вкладку «Кухни», прихожие — в «Прихожие», шкафы — в «Шкафы-купе» и т.д.
   - Модальное окно просмотра проекта (Lightbox) с возможностью листать фотографии в высоком разрешении и кнопкой заказа похожего проекта.

3. **Автономный ИИ-Агент синхронизации из VK (`server/sync-agent.js`):**
   - **Автоматическое обновление каждый 1 час (60 минут)** без вашего участия.
   - **Интеллектуальный фильтр жизнедеятельности:** автоматически отсекает бытовые посты, поздравления с праздниками, мемы, личные фото и спам. На сайт попадают только реальные мебельные проекты.
   - **ИИ-классификатор категорий:** анализирует текст, ключевые параметры, материалы и распределяет проект по нужным вкладкам.
   - **Оценка эстетики:** отбирает только четкие снимки интерьеров высокого разрешения, отсеивая мелкие иконки и аватарки.

4. **Интерактивный калькулятор стоимости под ключ:**
   - Выбор типа изделия (Кухня / Шкаф / Прихожая), плавная регулировка длины в метрах, выбор материалов фасадов (Egger, МДФ эмаль) и фурнитуры (Boyard, GTV, Blum).
   - Мгновенный расчет вилки стоимости с отображением подарка к заказу (Каменная мойка к кухне / Пескоструйный рисунок к шкафу / LED-подсветка).

5. **Полная русификация и адаптивность:**
   - Идеально отображается на смартфонах (375-430px), планшетах и мониторах 4K.
   - Прямая связь с мастером Борисом (`+7 (904) 521-66-62`) в один клик.

## 🚀 Запуск и тестирование на компьютере

Проект работает на чистом Node.js (v18+) без необходимости компиляции.

1. Откройте терминал в папке проекта:
   ```powershell
   cd "C:\Users\borya\OneDrive\Desktop\СайтМебель"
   ```

2. Запустите сервер и фонового агента:
   ```bash
   node server/sync-agent.js
   ```

3. Откройте в браузере:
   **http://localhost:3000**

Сервер сразу же выполнит первичный цикл синхронизации, загрузит базу проектов и запустит ежечасный фоновый интервал.

## 🌐 Выкладка сайта на хостинг и домен

Как только вы выложите проект на любой хостинг или VPS, фоновый агент автоматически продолжит синхронизацию раз в 1 час.

### Вариант 1: Обычный VPS / Сервер (Ubuntu, Debian, AlmaLinux)
1. Скопируйте файлы на сервер (через Git, SCP или панель Beget/TimeWeb/Reg.ru).
2. Запустите процесс в фоне через менеджер процессов `PM2`:
   ```bash
   npm install -g pm2
   pm2 start server/sync-agent.js --name "bona-mebel"
   pm2 save
   pm2 startup
   ```
3. Настройте Nginx или привяжите домен к порту 3000. Сайт будет работать и обновляться вечно.

### Вариант 2: Статический хостинг (GitHub Pages / Vercel / Timeweb Статика)
Папка `public/` является полностью автономным статическим веб-сайтом. Вы можете залить содержимое папки `public` на любой статический хостинг. База `data/portfolio.json` уже содержит проверенные проекты высокого качества.

## 🔑 Официальный VK API (Рекомендация)
По умолчанию агент работает автономно. Для того чтобы VK гарантированно никогда не выдавал капчу серверу при частых запросах, рекомендуется указать **Сервисный ключ доступа VK**:
1. Перейдите в [Управление приложениями VK](https://vk.com/apps?act=manage) и нажмите **«Создать приложение»** (тип: *Standalone* или *Сайт*).
2. В разделе **«Настройки»** скопируйте строку **«Сервисный ключ доступа»**.
3. Создайте в корне файл `.env` и вставьте ключ:
   ```env
   VK_SERVICE_TOKEN=ваш_ключ_vk
   ```
После этого агент будет мгновенно получать новые посты напрямую через защищенный API ВКонтакте.
